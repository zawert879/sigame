## Контекст — главный ресурс

Контекстное окно заполняется быстро → производительность деградирует.

- `/clear` между несвязанными задачами
- Subagents для исследований (чтобы не засорять основной контекст)
- После 2 неудачных исправлений → `/clear` и новый промпт с тем, что узнали

---

## Всегда давать проверку

Без проверки Claude останавливается когда работа «выглядит завершённой».

**Давать:** тесты, build exit code, скриншот, скрипт сравнения вывода.

Попросить Claude **показать доказательства** (вывод теста, команду), а не просто утверждать успех.

---

## Explore → Plan → Implement → Commit

1. Plan Mode: читать файлы, понять код
2. Plan Mode: создать подробный план
3. Implement: кодировать по плану, запустить тесты
4. Commit с описательным сообщением + PR

Для мелких задач (опечатка, переименование) — пропустить планирование.

## Конкретные промпты

| Расплывчато | Конкретно |
|---|---|
| "добавить тесты" | "написать тест для foo.py, граничный случай когда user вышел из системы, не мокировать" |
| "исправить баг логина" | "вход не работает после истечения сессии. Проверить src/auth/, написать failing тест, исправить" |
| "добавить виджет" | "смотреть HotDogWidget.php как пример, следовать паттерну, без новых библиотек" |

Расплывчатые промпты полезны только при исследовании.

## CLAUDE.md — коротко и по делу

**Включать:**
- Bash-команды которые Claude не угадает
- Правила стиля кода, отличающиеся от стандартов
- Архитектурные решения проекта
- Особенности окружения (нестандартные env vars)
- Неочевидные поведения и подводные камни

**Исключать:**
- Всё что Claude поймёт из кода
- Стандартные соглашения языка
- Подробную документацию API
- Самоочевидные практики

Раздутый CLAUDE.md → Claude игнорирует важные правила. Безжалостно обрезать.

## Инструменты организации

- **Skills** (`.claude/skills/`) — доменные знания по требованию, не в CLAUDE.md
- **Subagents** (`.claude/agents/`) — изолированные задачи, свежий контекст для review
- **Hooks** — детерминированные действия (в отличие от рекомендательных инструкций)
- **`/compact <instructions>`** — управляемое сжатие контекста с сохранением важного

---

## Параллельные сессии

- `claude --continue` — продолжить последнюю сессию
- `claude --resume` — выбрать из списка
- Worktrees — изолированные git checkouts для параллельной работы
- Writer/Reviewer паттерн: одна сессия пишет, другая (свежий контекст) ревьюит
